Desk file route after the review fix (isolated instance, loopback).
note.txt -> page.html, plan-link.md -> plan.md, out.txt -> a file outside the desk

== GET /api/bots/<id>/file?path=note.txt
HTTP/1.1 200 OK
Content-Disposition: inline; filename="note.txt"
X-Content-Type-Options: nosniff
Content-Type: text/plain;charset=utf-8

== GET /api/bots/<id>/file?path=page.html

Content-Security-Policy: sandbox allow-scripts allow-forms allow-popups allow-downloads
